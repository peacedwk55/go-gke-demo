ภาพที่ 1

commit เดินทางไปถึง pod ได้อย่างไร

เส้นที่สำคัญที่สุดคือ เส้นที่ไม่มี — CI ไม่เคยแตะคลัสเตอร์ มันแค่ commit บอกว่าใช้ image ตัวไหน แล้ว ArgoCD ในคลัสเตอร์ไปดึงเอง

ภาพที่ 2

อัปเดตแอปโดยไม่มี request หลุดเลย

maxUnavailable: 0 อย่างเดียวไม่พอ — pod เก่าต้องหยุด รับ traffic ก่อนหยุด ให้บริการ ช่องว่าง 5 วินาทีนี้คือกลไกทั้งหมด

ภาพที่ 3

เข้าถึง GCP ได้โดยไม่มีไฟล์ key

โจทย์ห้าม inject service account key — คำตอบคือแทน ไฟล์ credential ด้วย ความสัมพันธ์ความเชื่อถือ ที่ Terraform สร้างขึ้น

ภาพที่ 4

ทำไม Deployment ไม่มี replicas

ใส่ replicas + HPA + ArgoCD selfHeal = ชนกันสามทาง วนไม่จบ ทางแก้คือให้เจ้าของมีคนเดียว

ภาพที่ 5

ทำอย่างไรจึงจะได้ของขึ้นจริง

แถบเขียวคือขั้นที่รันจริงแล้ว ที่เหลือรออยู่ — รวมเวลา ~2 ชั่วโมง เสียเงิน ~฿30
